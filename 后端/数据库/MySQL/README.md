# MySQL

MySQL 作为世界上使用人数最多的三大关系型数据库之一, 它有着得天独厚的优势且大厂都在使用它, 那么学习 MySQL 就显得极为重要, 那么学习一定要从 实际出发 工作中并不是考验你的 知识储备而是考验 解决问题的能力, 他们是相辅相成的你的知识储备也决定着你能解决什么样的问题

我们主要学习 对 数据库/表 以及其中数据 增删改查 以及 函数/表关联等操作 以及 运维偏的 程序存储到服务器上/发生突发事件调用程序/不改变存储结构的情况下创建虚拟表进行查询, 最后还有性能优化问题(随着数据增多如何进行优化 的方法论) 以及设计字段表与优化技巧, 还有数据库设计的一些坑(如 MySQL 精度) 同时我们要知道 如何存储数据才可以高效查询
