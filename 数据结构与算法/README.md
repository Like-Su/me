# 数据结构与算法 引导页

> 这里我总结常用算法与 Leetcode 刷题思路, 算法思想以及设计思想

## 为何要学习算法与数据结构

我们从 What, Why, How 的角度来回答, 首先 来回答 "What" 什么是数据结构与算法, 你可能有听过一句话 `程序 = 数据结构 + 算法` 组成的什么是 算法和数据结构呢 它是用于存储管理数据的方式而算法是解决特定问题的步骤
其次我们来回答 "why" 为何要学习数据结构与算法,在当下AI时代我相信算法是面试时筛选候选人的指标之一 可以快速地判断候选人的能力 这是其中一个原因, 其次我们学习数据结构与算法 它可以帮助我们在 "在某些场景下通过数据结构来实现当前的最优解与提升系统设计的能力/提升解决问题的能力"
最后我们回答 "How", 如何学习数据结构与算法, 这里我提供我自己的学习策略

- 数据结构与算法核心就是 **结构定义 和 结构操作**, 结构是为操作而服务的
- 根据来历和解决的问题以及实际应用场景来学习(当你学习多了算法 你就会考试考虑代码性能)
- 边学边做,适度刷题
- 学习思想和操作
