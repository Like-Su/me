## 问题背景

在我们需要保存一系列相同类型的元素时我们应该如何来做呢?
数组就是解决这个问题的一种数据结构。(后续还会提到其他相关数据结构)

## 核心思想

数组底层通过连续的内存空间来实现数组按下标访问底层帮助我们做了 `index + offset` 的操作 所以我们可以直接将数组的下标作为偏移量来访问数组元素。

## 结构定义与操作

1. 结构定义

```c
typedef struct Array {
  // 数组容量
  size_t size;
  // 已使用容量
  size_t used;
  // 数据类型大小
  size_t typeSize;
  /**
   * @brief 值复制
   * @param dest 目标指针
   * @param src 源指针
  */
  void (*copy)(void *dest, const void *src);
  /**
   * @brief 释放数组占用的内存
   * @param value 数组指针
  */
  void (*destroy)(void *value);
  /**
   * @brief 比较两个元素
   * @param a 第一个元素指针
   * @param b 第二个元素指针
   * @return int 0 表示相等，-1 表示第一个元素小于第二个元素，1 表示第一个元素大于第二个元素
  */
  int (*compare)(const void *a, const void *b);
  // 存放数据的指针
  void *data;

} Array;
```

2. 支持操作

- 基础操作
  | 操作 | 描述 |
  | 初始化 | 初始化数组，设置数组容量为 N，已使用容量为 0 |
  | 随机访问 | 根据下标访问数组元素 |
  | push | 推入, 将元素添加到数组尾部 |
  | pop | 弹出, 从数组尾部弹出一个元素 |
  | sort | 排序 |
  | find | 查找元素 |
- 扩展操作
  | 操作 | 描述 |
  | 扩容 | 当元素数量超过数组容量时，需要扩容来存储新的元素 |
  | 反转 | 原地反转数组 |
  | 旋转 | 将数组元素向左旋转 k 个位置 |
  | 拼接 | 将两个数组拼接起来 |
