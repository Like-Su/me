## 学习设计模式的理由?
设计模式和基础学科相同都是你提高你开发能力的一道坎, 你可能觉得在开发中用不到设计模式那是因为还没有内化为自己的东西, 设计模式就像数据结构一样 设计模式是提高你代码的扩展性而数据结构是教你如何写出高性能代码
