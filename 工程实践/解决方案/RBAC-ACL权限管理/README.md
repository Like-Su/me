# RBAC & ACL
它们都是访问控制方案核心思想就是根据用户角色来分配系统访问权限

## RBAC(Role-Based Access Control)
RBAC 模型权限根据角色分配到个人, 用户通过成为角色成员获取这些权限 简化权限管理并提高灵活与维护性
- 核心思想: 根据用户角色分配权限
1. RBAC 基本组件
   1. 用户 (Users): 操作者/用户 也可以是服务账户
   2. 角色(Roles): 一个角色标识一组权限集合, 与工作职责相关
   3. 权限(Permissions): 对系统资源访问控制更加细颗粒化的 操作描述
2. RBAC 实施方法:
   1. 识别角色: 确定组织中不同角色与职责
   2. 定义权限: 明确用户需要哪些权限才可以执行
   3. 创建角色与分配权限:
   5. 分配角色给用户
