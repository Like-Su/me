## 流形调用
流形式调用有一个缺陷就是 在获取 JSON 数据时会不完整, 这是我们应该要解决的问题, 解决方案有两种
  - JSON 流式解析(NDJSON Newline-Delimited JSON) 输出内容分为多行每一行为一个独立 JSON
  - JSONStream 根据大模型输出JSON配合 JSONNStream(必须针对大模型特定结构进行处理, 而且只能在服务端使用)
  - 动态解析JSON 数据流

## 智能体构建
1. LLM 和 智能体区别
智能体就是能感知环境, 做出决策炳根据决策采取行动的系统. 智能体可以理解为 利用大模型核心能力通过适当流程编排构成能够感知理解分析环境信息并根据环境信息和知道信息进行综合处理 后输出反馈
