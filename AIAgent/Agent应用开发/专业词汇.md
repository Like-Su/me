# 专业词汇

|     中文      |     英文      |       说明        |
|     ---      |     ---      |       ---        |
|     函数      |     Function      |       输入输出建立映射也可以理解为 处理输入后形成输出结果        |
|     参数      |     Parameter      |       模型学习的权重和偏置        |
|     大模型      |     Large Language Model(LLM)      |       基于海量数据训练的神经网络语言模型        |
|     线性      |     Linear      |       输入输出可以直接推理        |
|     非线性      |     Nonlinear      |       输入输出有跳跃性        |
|     分布式编码      |     Distributed Representation      |       知识分散在一组参数组合中而非一对一存储        |
|     激活函数      |     Activation Function      |       非线性关键数学操作        |
