## 变量
从底层来看 变量 就是一个拿到内存中存储到的数据, 变量既地址

区别于静态语言, Python 为动态语言 定义变量无需关键字 而通过 `variable = value` 的形式 解释器就会认定该行为为 变量定义 行为, 而使用变量则和 常见语言相同 `print(variable)`, 动态语言类型是运行时确定的 所以我们定义变量后运行时 类型才可以确定下来

```python
url = 'https://google.com'
print(url)
```

## 格式化输出方式
1. 格式化分类:
  - C 风格式化
  - format 形式
  - f string 形式
  - Template 形式
```python
name = "LK"
tools = ["Codex", "ClaudeCode", "GLM5"]

# f string
print(f"My name is {name}.")
# C
print("My name is %s. tools %s" % (name, ",".join("%s" % tool for tool in tools)))

# format
print("My name is {}.".format(name))

# Template
from string import Template
print(Template("My name is $name.").substitute(name=name))
```
