# 响应式篇

## 如何理解响应式数据?
> 理解响应式 -> Vue2/Vue3 实现机制 -> 依赖收集
1. 响应式数据(ReactiveData): 核心就是 数据变化 UI 更新(建立数据与UI关联关系 当数据变化时系统会自动感知该变化并触发该数据 建立依赖关系的副作用重新执行 从而使得 使用依赖者 保持数据一致性)
2. Vue2/Vue3
  - Vue2 中内部通过 defineReactive 方法 既核心使用 `Object.defineProperty` 将属性进行劫持, 数组则是通过重写方法来实现劫持
  - Vue3 通过 Proxy 实现数据响应式()
3. 引伸: 深层对象通过递归来实现劫持
4. 源码实现:
  - Vue2: 每个属性拥有自己的 dep 属性, 作用就是保存 watcher 属性被更新时保存在 dep 中对应的 watcher 会更新
    - [Vue2 数据劫持 最小化实现](../../../code/Vue/defineReactive.js)
    - [Vue2 core](https://github.com/vuejs/vue/blob/9e88707940088cb1f4cd7dd210c9168a50dc347c/src/core/observer/index.ts#L128)
5. 性能优化:
  - 对象层级过深就会影响性能
  - 无需响应式内容不要放在 `data` 中
  - Object.free 可以冻结数据
## Vue 如何检测数组变化(2/3)
1. 如何检测数组变化: 
  - Vue2: 考虑性能问题 `defineProperty` 并没有对数组每项进行拦截, 而是重写方法 `push/shift/pop/splice/unshift/sort/reverse`

. 源码实现
  - Vue2: 通过函数劫持可以实现数组侦听 但是修改数组索引和长度是无法监控到的, 需要通过 7 种变异方法修改数组才会触发对应 watcher 更新, 数组中若有对象类型也会进行递归劫持, 需要通过索引更新方法需要采用 `Vue.$set` 来实现
    - [Vue2 数组变化检测](../../../code/Vue/arrayReactive.js)
    - [Vue2 官方数组检测](https://github.com/vuejs/vue/blob/9e88707940088cb1f4cd7dd210c9168a50dc347c/src/core/observer/array.ts#L25)
