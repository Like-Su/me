# 数据类型


## 数据类型检测
我们可以通过 `typeof` `instanceof(检测 当前实例是否属于该类)` `Object.prototype.toString.call(准确率高)` `constructor(构造函数判断)` 四种方案来进行类型检测
四种方案他们有对应的问题, 所以我们在特定情况下需要选择的来用
1. typeof: 基于数据类型值/二进制 (前缀) 进行检测, 无法检测 具体对象类型
```js
typeof 1 // number
typeof NaN // number
typeof '1' // string
typeof true // boolean
typeof undefined // undefined
typeof 1n // bigint

// 由于 null 在 编译器定义的是 0x00, 和 对象相同 所以 会被 typeof 检测为对象 
typeof null // object
typeof {} // object
typeof [] // object
typeof new Date() // object
typeof new Array() // object
typeof new RegExp() // object
typeof class P {} // function
typeof function () {} // function
```
2. instanceof: 可以解决 typeof 无法判断具体对象的问题, 但是问题就是他会顺原型链走 就是 只要当前类出现在原型链的路径上都会标识为成立
  - 开发者重构原型链后检测出来结果就是有问题的
  - 无法检测基本类型
```js
// instanceof 问题
[] instanceof Array // true
[] instanceof Object // true
[] instanceof Date // false
1 instanceof Number // false

function F() {}
F.prototype = Object.create(Array.prototype)

let f = new F
console.log(f instanceof Array) // true
```
3. constructor: 基本类型支持
- 开发者可以更改 constructor 所以会出现判断不准确的问题
```js
[].constructor === Array // true
[].constructor === Object // false
(1).constructor === Number // true
```
4. Object.prototype.toString.call 返回当前实例所属类信息
```js
Object.prototype.toString.call(1)
Object.prototype.toString.call(NaN)
Object.prototype.toString.call("")
Object.prototype.toString.call(true)
Object.prototype.toString.call(Symbol('a'))
Object.prototype.toString.call({})
Object.prototype.toString.call([])
Object.prototype.toString.call(/$/)
Object.prototype.toString.call(function () {})
Object.prototype.toString.call(new Date())
Object.prototype.toString.call(new RegExp())
Object.prototype.toString.call(null)
Object.prototype.toString.call(undefined)
Object.prototype.toString.call(BigInt(1))
```
